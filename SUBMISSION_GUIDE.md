# NAIS Submission Checklist

1. Public repository URL: `https://github.com/CSP-netizen/nais-engineering-portfolio`
2. Platform: GitHub
3. Repository name: `nais-engineering-portfolio`
4. Capture the **main repository screen** after confirming it is publicly accessible. The application expressly requires the main-screen screenshot for a public repository record.
5. Place the screenshot and the **separately prepared, reviewed portfolio PDF** in the NAIS evidence ZIP.
6. Determine the claimed contribution percentage truthfully for the application form. Do not automatically enter 100% because AI assistants helped produce some code.
7. Before submitting, review the PDF and screenshots for blind-hiring restrictions, student/personal information, and unverified performance claims.

This repository does **not** contain a final PDF because that document is being prepared and reviewed separately. Do not upload unreviewed private files to GitHub.
